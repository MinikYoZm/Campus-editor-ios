## Предметна область (Domain Model)

### Призначення застосунку
**TimeFlow** — це гейміфікований планувальник навчального розкладу, який перетворює університетську рутину на RPG-кампанію. Застосунок дозволяє студентам організовувати розклад, зберігати посилання на лекції та відстежувати дедлайни, перетворюючи звичайні пари та лабораторні на "квести", виконання яких дає відчуття прогресу, одразу через додаток переходити на Zoom, Meet та інші.

### Цільовий користувач
Студент університету, якому потрібно тримати розклад, посилання на онлайн-лекції, імена викладачів та нотатки в одному організованому місці. 

### Основні сценарії використання
1. **Перегляд розкладу:** Користувач відкриває застосунок і бачить розклад на поточний тиждень у вигляді сітки з часовими слотами.
2. **Створення пари:** Користувач взаємодіє з вільним слотом, заповнює картку заняття (назва дисципліни, "NPC-викладач", нотатки, посилання на підключення) і зберігає її.
3. **Сповіщення:** Система автоматично надсилає користувачу push-сповіщення з посиланням на пару за певний час до її початку.
4. **Управління завданнями (у перспективі):** Додавання конкретних завдань до предметів (наприклад, "захистити лабораторну з ПРО") з можливістю відмітити їх як виконані.

### Основні сутності (Entities)
* **`Lesson` (Пара/Квест):** Структура, що описує базову одиницю розкладу.
  * *Властивості:* `title` (назва), `lecturer` (викладач), `weekday` (день тижня), `timeSlot` (час), `meetingLink` (посилання, Optional), `notes` (нотатки, Optional), `isCompleted` (статус).
* **`ScheduleManager` (Журнал розкладу):** Клас, що керує колекцією всіх створених занять (`Lesson`).
  * *Функції:* додавання нової пари, фільтрація подій за днем тижня, підрахунок загального прогресу закритих завдань.


## Технічні рішення (Базові конструкції Swift)
У файлі `Schedule.swift` реалізовано:
- **Enum:** `DayOfWeek` для безпечного визначення днів тижня.
- **Protocol:** `ScheduleItem` для абстракції елементів розкладу.
- **Struct / Class:** Використано структуру `Lesson` (семантика значення для даних) та клас `Schedule` (семантика посилання для управління логікою).
- **Optionals:** Поля `meetingLink` та `notes` можуть бути порожніми, розгортання виконано безпечно через `if let`.
- **Колекції та цикли:** Зберігання пар у масиві `[Lesson]` та фільтрація через метод `filter` / цикл `for-in`.

## Де реалізовано потрібні конструкції в коді?
### 1. Протокол (`protocol`)
Визначає контракт та базові вимоги для будь-якого елемента/завдання у застосунку.
* **Де шукати в коді:** Рядки 3–7 (`protocol QuestItem`).
* **Особливості:** Оголошує властивості `title` (тільки для читання) та `isCompleted` (читання/запис), а також метод `mutating func completeQuest()`.

### 2. Перерахування (`enum`)
Використовується для суворо типізованого списку днів тижня з прив'язкою до рядкових значень (`RawValue`).
* **Де шукати в коді:** Рядки 10–17 (`enum WeekDay: String`).
* **Особливості:** Зберігає назви днів українською мовою (`case monday = "Понеділок"` і т.д.), що зручно для виведення в інтерфейс чи консоль.

### 3. Структура (`struct`) з семантикою значення та `mutating` методами
Описує конкретну пару (квест) у розкладі.
* **Де шукати в коді:** Рядки 20–39 (`struct Lesson: QuestItem`).
* **Особливості:** 
  * Реалізує протокол `QuestItem`.
  * Має константи (`let`) для незмінних даних (`title`, `lecturer`, `weekday`, `timeSlot`) та змінні (`var`) для статусів.
  * Використовує ключове слово `mutating` у методі `completeQuest()`, оскільки структури є типами значень і за замовчуванням не можуть змінювати власні властивості зсередини.

### 4. Клас (`class`) із семантикою посилання
Керує колекцією пар, інкапсулює логіку додавання, пошуку та фільтрації.
* **Де шукати в коді:** Рядки 42–89 (`class ScheduleManager`).
* **Особливості:** 
  * Має приватну колекцію `private var lessons: [Lesson]` для захисту даних від прямого неконтрольованого змінення ззовні.
  * Надає методи `addLesson`, `completeQuestInSchedule` та `showSchedule`.

### 5. Робота з Optional та безпечне розгортання (`Optional Binding`)
Посилання на онлайн-зустріч та нотатки можуть бути відсутніми.
* **Де шукати в коді:** 
  * Оголошення: рядки 28–29 (`meetingLink: String?`, `notes: String?`).
  * Безпечне розгортання: рядки 80–84 (`if let link = lesson.meetingLink { ... } else { ... }`).

### 6. Колекції, замикання (`Closures`) та умовні конструкції / цикли
* **Фільтрація за допомогою замикання:** рядок 67 (`lessons.filter { $0.weekday == day }`).
* **Пошук індексу за умовою:** рядок 54 (`lessons.firstIndex(where: { $0.title == title })`).
* **Умовні розгалуження та цикли:** рядки 69–85 (`if filteredLessons.isEmpty` та цикл `for lesson in filteredLessons`).

## Як перевірити сценарій?
Для демонстрації роботи всіх описаних компонентів створено спеціальну тестову функцію `runTimeFlowScenario()`.

### Крок 1. Інтеграція виклику
Переконайтеся, що функція `runTimeFlowScenario()` викликається у вашому додатку:
* Якщо це консольний додаток (`main.swift`): просто викличте `runTimeFlowScenario()`.
* Якщо це проєкт SwiftUI (наприклад, у `ContentView.swift` всередині `body` або `onAppear`): додайте виклик функції при завантаженні екрана.

### Крок 2. Очікуваний сценарій виконання
Під час запуску функції `runTimeFlowScenario()` відбуваються такі етапи:
1. **Створення менеджера:** Ініціалізується порожній `ScheduleManager`.
2. **Створення даних:** Створюються дві пари на понеділок:
   * **PRO** (викладач Homal D.R., час 08:30, є посилання на Zoom).
   * **IOS** (викладач Jenkins P.D., час 10:25, посилання відсутнє — `nil`).
3. **Додавання до бази:** Викликається метод `addLesson`, який виводить у консоль повідомлення про успішне додавання.
4. **Зміна стану:** Викликається `completeQuestInSchedule(title: "PRO")`. Менеджер знаходить пару "PRO" в колекції та змінює її статус виконання (`isCompleted = true`), виводячи повідомлення про виконання квесту.
5. **Виведення результатів:**
   * Викликається `mySchedule.showSchedule(for: .monday)`. У консолі з'явиться детальний розклад на понеділок, де біля пари **PRO** буде стояти позначка завершення `[X]` та посилання, а біля **IOS** — незаповнений квадрат `[ ]` із приміткою про відсутність посилання.
   * Викликається `mySchedule.showSchedule(for: .tuesday)`. Оскільки на вівторок пар не додано, виведеться повідомлення: `"На цей день пар немає! Можна відпочивати."`.
