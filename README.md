# Campus-editor

## Предметна область (Domain Model)

### Призначення застосунку
**Campus-editor** — це мобільний застосунок для зручного планування та управління навчальним розкладом. Він дозволяє студентам створювати розклад пар на тиждень, зберігати важливу інформацію про кожну дисципліну та вчасно отримувати нагадування.

### Цільовий користувач
Студент університету, якому потрібно тримати розклад, посилання на онлайн-лекції, імена викладачів та нотатки в одному організованому місці. 

### Основні сценарії використання
1. **Перегляд розкладу:** Користувач відкриває застосунок і бачить розклад на поточний тиждень у вигляді сітки з часовими слотами.
2. **Створення пари:** Користувач натискає на вільний часовий слот у певний день, заповнює форму (назва дисципліни, викладач, нотатки, посилання на відеодзвінок) і зберігає пару.
3. **Сповіщення:** Система автоматично надсилає користувачу push-сповіщення з посиланням на пару за певний час до її початку.
4. **Управління завданнями (у перспективі):** Додавання та відстеження виконання конкретних завдань до створеної пари.

### Основні сутності (Entities)
- **`Lesson` (Пара):** Структура, що описує конкретне заняття. 
  - *Властивості:* назва, викладач, день тижня, часовий слот, посилання, нотатки.
- **`Schedule` (Розклад):** Клас або колекція, що керує збереженням усіх створених занять (`Lesson`).
  - *Функції:* додавання нової пари, фільтрація занять за певним днем тижня.
