## Предметна область (Domain Model)

### Призначення застосунку
**TimeFlow** — це гейміфікований планувальник навчального розкладу, який перетворює університетську рутину на RPG-кампанію. Застосунок дозволяє студентам організовувати розклад, зберігати посилання на лекції та відстежувати дедлайни, перетворюючи звичайні пари та лабораторні на "квести", виконання яких дає відчуття прогресу, одразу через додаток переходити на Zoom, Meet та інші.

### Цільовий користувач
Студент університету, якому потрібно тримати розклад, посилання на онлайн-лекції, імена викладачів та нотатки в одному організованому місці. 

### Основні сценарії використання
1. **Перегляд розкладу:** Користувач відкриває застосунок і бачить розклад на поточний тиждень у вигляді сітки з часовими слотами.
2. **Створення пари:** Користувач взаємодіє з вільним слотом, заповнює картку заняття (назва дисципліни, "NPC-викладач", нотатки, посилання на підключення) і зберігає її.
3. **Сповіщення:** Система автоматично надсилає користувачу push-сповіщення з посиланням на пару за певний час до її початку.
4. **Управління завданнями (у перспективі):** Додавання конкретних завдань до предметів (наприклад, "захистити лабораторну з ПРО") з можливістю відмітити їх як виконані.

### Основні сутності (Entities)
* **`Lesson` (Пара/Квест):** Структура, що описує базову одиницю розкладу.
  * *Властивості:* `title` (назва), `lecturer` (викладач), `weekday` (день тижня), `timeSlot` (час), `meetingLink` (посилання, Optional), `notes` (нотатки, Optional), `isCompleted` (статус).
* **`ScheduleManager` (Журнал розкладу):** Клас, що керує колекцією всіх створених занять (`Lesson`).
  * *Функції:* додавання нової пари, фільтрація подій за днем тижня, підрахунок загального прогресу закритих завдань.


## Технічні рішення (Базові конструкції Swift)
У файлі `Schedule.swift` реалізовано:
- **Enum:** `DayOfWeek` для безпечного визначення днів тижня.
- **Protocol:** `ScheduleItem` для абстракції елементів розкладу.
- **Struct / Class:** Використано структуру `Lesson` (семантика значення для даних) та клас `Schedule` (семантика посилання для управління логікою).
- **Optionals:** Поля `meetingLink` та `notes` можуть бути порожніми, розгортання виконано безпечно через `if let`.
- **Колекції та цикли:** Зберігання пар у масиві `[Lesson]` та фільтрація через метод `filter` / цикл `for-in`.
